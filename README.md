# Gym Tracker

Вебтрекер силових тренувань: спланував тренування → виконав у залі, відмічаючи підходи → переглянув історію «план / факт». Курсова робота з дисципліни «Проектування інформаційних систем».

- **Бекенд:** NestJS 12, PostgreSQL 18, Drizzle ORM, JWT.
- **Фронтенд:** React 19, Vite, TanStack Query, Tailwind + shadcn/ui (mobile-first).
- **Спільні контракти:** zod-схеми в пакеті `shared/`.

## Що потрібно

- Node.js ≥ 24.15
- pnpm 11 (`corepack enable`)
- PostgreSQL (перевірено на 18)

## Запуск

```bash
pnpm install
createdb gym_tracker               # порожня база (або CREATE DATABASE gym_tracker;)
cp .env.example .env               # заповнити DATABASE_* (для локальної БД host = localhost) і JWT_SECRET (openssl rand -base64 32)
pnpm db:migrate                    # створити таблиці
pnpm db:seed                       # 876 вправ + демо-користувач із тренуваннями
node scripts/exercises/build.mjs   # картинки вправ (~100 МБ, один раз); без них усе працює, лише без зображень
pnpm dev
```

- Сайт: http://localhost:5173 (зручніше у вигляді телефона: DevTools → Toggle device toolbar).
- API і Swagger: http://localhost:3000/docs
- Якщо порт 3000 зайнятий, змініть у `.env` разом `API_PORT` і `VITE_API_URL` (наприклад, 3100 і http://localhost:3100).

`pnpm db:seed` можна запускати повторно: вправи оновлюються, демо-користувач створюється заново з датами відносно сьогодні.

## Як користуватись

1. **Тренування → «Нове тренування»**: додати вправи з каталогу, задати вагу й повтори підходів, «Готово».
2. **«Почати»** біля запланованого тренування (або «Почати без плану»). У залі вводити фактичні вагу й повтори, відмічати підходи ✓.
3. **«Завершити»**: тренування переходить в **Історію** з таблицею «План / Факт». Звідти його можна повторити як нове заплановане.
4. **Вправи**: пошук українською чи англійською, фільтри за м'язами, обладнанням, категорією; власні вправи.

## Команди

| Команда | Що робить |
|---|---|
| `pnpm dev` | API (:3000) і веб (:5173) з автоперезапуском |
| `pnpm build` | збірка всіх пакетів |
| `pnpm typecheck`, `pnpm lint` | перевірка типів, лінтер (oxlint) |
| `pnpm db:generate` | нова міграція після зміни `api/src/db/schema.ts` |
| `pnpm db:migrate` | застосувати міграції |
| `pnpm db:seed` | вправи + демо-користувач |
| `pnpm db:schema` | оновити [docs/schema.sql](docs/schema.sql): повний SQL-скрипт створення БД |

## Структура

```
api/      NestJS: модулі auth, exercises, workouts; схема БД і міграції (api/drizzle)
web/      React SPA
shared/   zod-схеми запитів і відповідей, довідники з українськими підписами
scripts/  підготовка даних вправ
docs/     документація, SQL-схема
```
